# Pride Prank Lab

An optional, click-through Windows overlay for ChatGPT/Codex, Discord, Chrome, and Steam. It does not inject code or modify app packages.

The resting defaults are intentionally restrained:

- Slow rainbow border.
- No continuous confetti.
- No banner or disco glow.
- 35% intensity.
- Five-second native accent cycle where Windows supports it.

Use **Celebrate** for a short six-second burst. Reduced-motion and native theme adapters should be preferred for everyday use.

Build with `./build.ps1`.
