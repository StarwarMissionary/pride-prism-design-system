# Obsidian theme

A dark theme for the Obsidian note app built on the shared roles. Surfaces, text, accent, selection, links and status colors map onto Obsidian's documented CSS variables; a static identity rail sits along the top edge of the workspace. Light mode is left to Obsidian's defaults.

Build a palette, then copy `dist/<palette>/adapters/obsidian` to `<vault>/.obsidian/themes/Pride Prism/` (the folder name must match `name` in `manifest.json`). Select it under Settings > Appearance > Themes. To undo, choose another theme; vault contents are never touched.

Reference: [Obsidian CSS variables](https://docs.obsidian.md/Reference/CSS+variables/Foundations/Colors), [Build a theme](https://docs.obsidian.md/Themes/App+themes/Build+a+theme).
