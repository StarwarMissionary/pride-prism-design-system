# Chrome start page

This Manifest V3 extension replaces Chrome's new-tab page with a dark Pride Prism dashboard. It includes local search, a clock, editable shortcuts, and a short user-triggered celebration. Shortcut preferences stay in the extension's local storage.

The extension requests no permissions and contains no remote code, analytics, ads, or browsing-data access.

## Install

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this `chrome-start-page` folder.
4. Approve Chrome's new-tab-page change notice if it appears.

Chrome deliberately requires the person using the browser to perform these installation steps. Disable or remove **Pride Prism Start Page** from `chrome://extensions` to restore Chrome's standard new-tab page.
