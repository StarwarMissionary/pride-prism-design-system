04 · Motion

Celebration,
with restraint.

Core transitions finish in 160–280 ms. Ambient accents move on a slow five-second cycle. Decorative bursts last six seconds and require an explicit action.

  • 160 ms Focus and hover response
  • 280 ms Standard interface transition
  • 5 s Optional ambient accent cycle
  • 0 Continuous effects enabled by default
